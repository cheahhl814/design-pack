v0.16.0 · Live demos

html-template-pack

Four self-contained annotated HTML templates + a zero-dependency graphics pack + a 93-template hand-drawn SVG diagram library. Every template carries inline review annotations, a theme toggle, and density + font-size controls. Dark-first by default; light mode one click away.

What's new in v0.16.0 — the SVG diagram library grew to 93 components with 16 science & technology visuals: ecosystems (food web, energy pyramid, water and nitrogen cycles, symbiosis, succession, ocean zones), earth & physical science (plate boundaries, reaction energy profile, states of matter, EM spectrum), lab & biotech (CRISPR, immune response, PCR cycling) and technology (transformer block, API request lifecycle). v0.15.0 added six cladograms (trait ladder, labelled parts, character matrix, nested sets, circular fan, one tree three ways). v0.14.0 brought a pipeline metro map, mind map, org chart, 8-step ring and more; a dotted world map and a Europe tile grid; climate visuals (warming stripes, carbon cycle, sea-level rise, Paris thermometer); and lab & life-science visuals (DNA helix, central dogma, cell membrane, Punnett square, gel, 96-well plate). New bin/svg-export.js turns any component into a standalone .svg that renders in PowerPoint, Word, Figma and Inkscape. Browse them in the SVG library demo below.
