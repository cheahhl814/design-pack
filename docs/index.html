design-pack

The design layer for GenOffice (a mandatory dependency): a 128-component SVG diagram library that recolours to the document it goes into (slide-set palette, tokens JSON, or a .pptx/.docx theme), 13 SVG slide-design theme sets that build native, editable .pptx decks through GenOffice, and one themed report template with annotations and a zero-dependency CSS graphics pack.

What's new in v1.0.0: GenOffice integration. svg-export.js --palette recolours any diagram to a slide set, a tokens JSON, or your own pptx/docx theme (try the Palette switcher in the SVG library); genoffice-bridge.js turns slide payloads into native pptx decks (art as PNG, titles and body as editable text). The bento and dashboard templates were retired; tag v0.37.0-final keeps them.
