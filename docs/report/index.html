    Headline result

    📈 Community diversity index drops 18% over 24 months

    Bayesian occupancy model, controlling for survey effort and seasonal noise, shows a significant negative trend (β = −0.91, 95% CI [−1.12, −0.70]) across the 12 re-surveyed sites. The effect is strongest at edge-affected sites and absent at the marine-park reference.

    Secondary findings

    ✓ Generalist species resilient

    Three generalist species (A. fulva, C. auritus, M. musculus) maintained or increased occupancy across all 12 sites despite the overall diversity decline.

    ⚠ Edge-effect threshold

    Sites within 800m of land-use change boundaries show the steepest decline. Below 200m the effect plateaus, suggesting a saturation effect that may be reversible with active management.

    💡 Acoustic baseline established

    Continuous hydrophone deployment at 3 reference stations generated 4.2 TB of raw audio. A 6-month pilot analysis shows a 12% increase in anthropogenic noise events vs. the 2023 baseline.

    💡 eDNA detection rate

    Metabarcoding recovered 41% more species per litre than visual census alone, including 3 cryptic species not previously recorded at the survey sites.

    ANNOTATIONS

    How annotations work

    PROJECT / EVENT LABEL

    Each note stores the highlighted quote (or the caret position for inserts) plus its surrounding text and nearest heading, so it re-anchors even if the document is regenerated with minor changes. Diagrams and code (anything inside .mermaid, svg, or a data-annot-skip element) are ignored, so rendering them never shifts your highlights. Exported JSON carries the type (comment / delete / insert / replace / question / format) and a replacement field for structured edits — downstream revision agents don't need to parse free-text intent. question notes carry answer/answered fields: an agent can answer them by re-importing a JSON file containing just the matching id plus answer — the importer merges it onto the existing note instead of overwriting it. format notes carry a style field (bold / italic / underline / sup / sub / highlight:<color> / color:<color>).

    The v2 engine reads each [data-panel] to know which section a highlight belongs to. When you click a drawer entry, the engine switches the matching tab before scrolling the highlight into view, so reviews can hop between findings and methodology without losing their place.
