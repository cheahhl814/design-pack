svg-slides

Slide designs with slot markers, in 5 theme sets. Every set ships the same six slide designs with the same slot names, so one payload re-themes with --set. Each card is the design composed with its sample payload by bin/compose-slide.js. Real output bakes colours to hex for one theme; here the slide stays token-driven so you can preview both palettes. Graphic slots hold svg-library components.
